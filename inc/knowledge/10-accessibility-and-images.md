# Accessibility & Images

When you upload an image to your site, adding a short text description — called **alt text** — makes a meaningful difference. It helps visually impaired visitors who use screen readers understand what an image shows, and it also helps search engines index your content correctly.

It takes less than a minute per image and is one of the simplest ways to make your site more inclusive.

---

## Where to Add Alt Text

Alt text can be added when uploading a new image or at any time by editing an existing one in the media library.

1. Go to [**Media**](upload.php) in the admin menu.
2. Click the image you want to update.
3. Find the **Alt Text** field in the panel on the right.
4. Add your description and click **Save**.

Alt text set in the media library carries through automatically when the image is used anywhere on the site.

---

## How to Write Good Alt Text

Good alt text describes what the image shows clearly and concisely — usually one sentence is enough.

| Image | Good alt text |
|---|---|
| A photo of your shopfront | `Exterior of Smith & Co on George Street, Sydney` |
| A team headshot | `Jane Smith, Senior Consultant` |
| A before and after renovation photo | `Bathroom renovation — before and after` |
| A service icon | `Plumbing services` |

**Keep it short.** A sentence or two is ideal — screen readers read alt text aloud, so lengthy descriptions become difficult to listen to.

**Describe what matters.** Focus on the content and context of the image, not how it looks. "Photo of a smiling woman" is less useful than "Sarah Jones, Practice Manager".

**Don't start with "Image of" or "Photo of".** Screen readers already announce that it's an image — you don't need to repeat it.

---

## When to Leave Alt Text Blank

Not every image needs alt text. Decorative images — ones that are purely visual and don't add information — should have their alt text left empty. This tells screen readers to skip over them entirely, which makes for a smoother experience.

Examples of decorative images:
- Background textures or patterns
- Divider graphics
- Icons that are already described by a text label next to them

---

## Images in the Page Editor

When swapping an image directly inside Bricks Builder, you can also set alt text from the image settings panel on the left. If the image already has alt text set in the media library, it will pre-fill automatically.

> If you're unsure whether an image needs alt text, err on the side of adding it — a description is always better than nothing.
