# Uploading Media

The Media Library is where all images, documents, and files on your site are stored. Anything you upload — whether through a page, a collection, or directly — lives here and can be reused across the site.

---

## Accessing the Media Library

Go to [**Media**](upload.php) in the left-hand admin menu. You'll see a grid of everything currently uploaded to the site.

Your media library has a **folder panel on the left** that keeps files organised by category. Click any folder to filter the library to just that folder's contents, making it much easier to find what you're looking for without scrolling through everything.

### Working with Folders

- **Browse** — click a folder in the sidebar to view its contents
- **Create a folder** — right-click in the sidebar panel and choose **Add Folder**, or click the add icon at the top of the panel
- **Create a subfolder** — right-click an existing folder and choose **Add Subfolder**
- **Rename or delete a folder** — right-click the folder for options
- **Move files into a folder** — select one or more files and drag them into a folder in the sidebar, or right-click a file and choose **Move to Folder**
- **Upload directly into a folder** — click the folder first to open it, then upload as normal and the files will land there automatically

Use the search bar at the top of the library to find a specific file by name regardless of which folder it's in.

---

## Uploading a New File

1. Go to [**Media → Add New**](media-new.php).
2. Drag and drop your file onto the upload area, or click **Select Files** to browse your computer.
3. The file will upload and appear in the library automatically.

You can upload multiple files at once by selecting more than one in the file browser.

---

## Supported File Types

| Type | Formats |
|---|---|
| **Images** | JPG, PNG, WebP, GIF, SVG |
| **Documents** | PDF, DOC, DOCX, XLS, XLSX |
| **Video** | MP4, MOV (though large video files are better hosted on YouTube or Vimeo) |

---

## Image Size Recommendations

Uploading very large images slows the site down for visitors. Before uploading, resize images so they're no larger than necessary:

- **Full-width banner images** — 1920px wide maximum
- **Content images** — 1200px wide is usually plenty
- **Logos and icons** — upload at the size they'll be displayed

If you're unsure, your developer can advise on what's appropriate for a specific area of the site.

---

## Editing File Details

After uploading, click any file in the library to open its details panel. From here you can:

- Update the **Alt Text** — a short description of the image used by screen readers and search engines
- Update the **Title** and **Caption** if needed
- Copy the **File URL** to link to it directly

> Alt text is important for accessibility and SEO. See the **Accessibility & Images** article for guidance on writing it well.

---

## Deleting a File

Click a file in the library to open its details, then click **Delete Permanently**.

> Before deleting, make sure the file isn't in use anywhere on the site. Deleting an image that's still referenced on a page will leave a broken image in its place.
