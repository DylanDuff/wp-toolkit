# Plugin & WordPress Updates

Your site runs on WordPress, which powers the core platform, along with a set of plugins that handle things like the page builder, forms, SEO, and other functionality. Keeping these up to date is important — and it's handled for you.

---

## How Updates Are Managed

WordPress core, plugins, and themes are updated regularly as part of your site maintenance. Updates are reviewed and applied on your behalf, keeping the site secure and running on current, supported software.

Before updates are applied, a backup is taken automatically — so if an update ever causes an unexpected issue, we can roll back immediately. See the **Backups** article for more on how that works.

---

## Why Updates Matter

Updates aren't just about new features. The majority are released to:

- **Fix security vulnerabilities** — outdated plugins are one of the most common ways sites get compromised
- **Maintain compatibility** — WordPress itself updates regularly, and plugins need to keep pace
- **Fix bugs** — stability and performance improvements come through updates too

A site left without updates for an extended period becomes a security risk and can start to break as components fall out of sync with each other.

---

## What to Do If Something Looks Off

Occasionally an update can change how something looks or behaves in an unexpected way. If you notice anything unusual after an update:

- Note which page or feature seems affected
- Get in touch and let us know what you're seeing

We monitor sites after updates, but you know your site's content better than anyone — if something doesn't look right, flag it.

---

## Installing Plugins Yourself

If you have administrator access and are considering installing a new plugin, please check with us first. Plugins vary significantly in quality, and a poorly built one can conflict with existing functionality, slow the site down, or introduce security vulnerabilities. A quick message before installing can save a lot of troubleshooting later.
